# Seb-GRAF/homebrew-tap

Homebrew casks for [StableBar](https://github.com/Seb-GRAF/StableBar), a native, configurable menu bar for macOS. Install it with `brew install --cask seb-graf/tap/stablebar`. Each stable release of StableBar updates the cask here. StableBar also updates itself, so `brew upgrade` skips it unless you pass `--greedy`.
